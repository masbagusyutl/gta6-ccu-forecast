Hour-by-hour forecast of GTA VI's launch-day Twitch concurrent viewers, as five quantiles per hour, from the first hour's print plus the launch curves of 38 comparable big game launches. The model works in log space: a per-hour shape ratio to the hour-1 print (median across comparables, scale-adjusted), with per-hour spreads calibrated from the cross-launch dispersion, and an unlock-wave shape for the midnight-local rollout.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
